# Simple Calculator

## Description
A simple calculator developed using Python that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input and result display

## Technology Used
- Python

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Run the Python file.
4. Enter the numbers and select an arithmetic operation.
